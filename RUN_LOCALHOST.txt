SMARTLIB - LOCALHOST & VS CODE RUN GUIDE
========================================

OPTION 1: RUN IN VS CODE (RECOMMENDED)
--------------------------------------
1. Open this folder in VS Code:
   File -> Open Folder -> Select this SmartLib folder.

2. Install Recommended Extensions (if prompted):
   - Python (ms-python.python)
   - Python Debugger (ms-python.debugpy)

3. Run the Server:
   - Simply press F5 (or go to Run -> Start Debugging).
   - Alternatively, open the VS Code Terminal and select:
     Terminal -> Run Task... -> "2. Start SmartLib Server"

4. Open your browser:
   http://127.0.0.1:5000

5. Login:
   - Admin with Google: Click "Continue with Google" (sanskargirase787@gmail.com).
   - Admin with Password: username `admin`, password `Admin@SmartLib2026!`.


OPTION 2: ONE-CLICK WINDOWS RUN
-------------------------------
Double-click:
    run_smartlib.bat

It will automatically find your Python interpreter, start Flask, and open on:
    http://127.0.0.1:5000


OPTION 3: MANUAL TERMINAL SETUP
-------------------------------
Open terminal in this directory:
    python -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python app.py


CONFIGURATION:
--------------
- The `.env` file is pre-configured for Firebase Cloud Firestore & Google Sign-In.
- For local testing, `SESSION_COOKIE_SECURE` is set to `false`.
- When deploying to production HTTPS (e.g. Render), set `SESSION_COOKIE_SECURE=true`.
